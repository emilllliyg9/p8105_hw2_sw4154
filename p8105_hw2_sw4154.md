# Problem 1

First, I import the NYC Transit dataset, retain the requested variables,
and convert the `entry` variable from a character variable to a logical
variable.

``` r
transit_data =
  read_csv(
    "data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
    na = c("NA", "")
  ) |>
  clean_names() |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    route1:route11,
    entry,
    vending,
    entrance_type,
    ada
  ) |>
  mutate(
    entry = case_match(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    )

```

The cleaned transit dataset contains information about subway entrances
and exits, including station name and line, station coordinates, routes
served, entry and vending status, entrance type, and ADA compliance. I
standardized the variable names, retained the requested variables, and
converted `entry` from `YES`/`NO` values to a logical variable.

The resulting dataset has 1868 rows and 19 columns. The dataset is not
tidy because the routes served by each station are spread across
`route1` through `route11` instead of being stored in a single route
variable.

## Baseline demographic data

The baseline file begins with a descriptive row, so I skip that row
during import. I also treat `.` as a missing value, clean the variable
names, convert sex and APOE4 carrier status to factors with descriptive
labels, and remove participants who had MCI at baseline.

``` r
mci_baseline =
  read_csv(
    "data/MCI_baseline.csv",
    skip = 1,
    na = "."
  ) |>
  clean_names() |>
  filter(
    is.na(age_at_onset) |
      age_at_onset > current_age
  ) |>
  mutate(
    sex = case_match(
      sex,
      0 ~ "Female",
      1 ~ "Male"
    ) |>
      factor(
        levels = c("Female", "Male")
      ),
    apoe4 = case_match(
      apoe4,
      0 ~ "Non-carrier",
      1 ~ "Carrier"
    ) |>
      factor(
        levels = c("Non-carrier", "Carrier")
      )
  )
```

## Longitudinal amyloid data

The amyloid file also begins with a descriptive row, so I skip that row
during import. I reshape the visit-specific columns into long format so
that each row represents one observed biomarker measurement for one
participant.

``` r
mci_amyloid =
  read_csv(
    "data/mci_amyloid.csv",
    skip = 1
  ) |>
  clean_names() |>
  pivot_longer(
    baseline:time_8,
    names_to = "visit",
    values_to = "amyloid_42_40"
  ) |>
  mutate(
    time_years = case_match(
      visit,
      "baseline" ~ 0,
      "time_2" ~ 2,
      "time_4" ~ 4,
      "time_6" ~ 6,
      "time_8" ~ 8
    )
  ) |>
  drop_na(amyloid_42_40) |>
  select(
    id = study_id,
    time_years,
    amyloid_42_40
  )
```

The cleaned amyloid dataset contains 2272 observed biomarker
measurements from 487 participants. Each row includes a participant ID,
the number of years since baseline, and the measured amyloid beta 42/40
ratio.
